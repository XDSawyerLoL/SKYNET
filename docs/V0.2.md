# SKYNET V0.2 — Windows / MCP / Skills

V0.2 turns the V0.1 local chat-and-tools core into the beginning of a sovereign desktop agent.

## Added

- Native Windows top-level window discovery.
- Windows UI Automation accessibility snapshots.
- Permission-gated focus, UI invoke and text input.
- Permission-gated screenshots stored inside the workspace.
- Optional local Ollama vision model for screenshot analysis.
- Minimal dependency-free MCP stdio client and configurable local MCP hub.
- Structured plans with per-step status/evidence.
- Persistent reusable Markdown skills that can be learned after a successful procedure.
- Expanded audit/permission coverage.

## Operating model

SKYNET prefers:

1. Read-only Windows accessibility inspection.
2. Deterministic UI Automation actions.
3. Screenshot + local vision only when accessibility data is insufficient.
4. MCP tools for external capabilities.
5. PowerShell as an explicit permission-gated fallback.

## MCP config

Create `.skynet/mcp.json`:

```json
{
  "servers": {
    "example": {
      "command": "python",
      "args": ["path/to/server.py"],
      "env": {}
    }
  }
}
```

MCP tool calls require user confirmation by default.

## Skill learning

A skill is deliberately data, not executable self-modifying code. A good skill contains:

- purpose,
- preconditions,
- ordered steps,
- verification,
- failure recovery.

`save_skill` is confirmation-gated. This lets SKYNET accumulate know-how without silently rewriting its own trusted core.
